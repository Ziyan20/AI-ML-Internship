# 💻 Major Project

## 🌍 Disaster Tweet Classification

### Overview

Disaster Tweet Classification is a Natural Language Processing (NLP) project that predicts whether a tweet is related to a real disaster or not.

The objective is to assist emergency responders by automatically filtering disaster-related tweets from large volumes of social media posts.

---

## 📌 Problem Statement

Social media platforms generate thousands of tweets every minute.

During emergencies, manually identifying relevant disaster-related tweets becomes difficult.

This project applies Machine Learning techniques to classify tweets into:

- ✅ Disaster Tweet
- ❌ Non-Disaster Tweet
